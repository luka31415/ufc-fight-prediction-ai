# Data

I do not commit the full local research dataset to GitHub. My working data directory contains generated UFCStats tables, matched odds, model-development intermediates, MMA Decisions caches, Sherdog caches, and experiment outputs.

The code and reports in this repository document the expected filenames and schemas. Large/generated data should be rebuilt locally or copied into this directory from my private working archive.

The most important production input currently expected by the command-line scripts is `training_data_with_odds.csv`.
